# Kusenindo UPVC Makassar

Situs company profile statis empat halaman berdasarkan brief dan rancangan Stitch:

- `index.html` — Beranda
- `produk.html` — Produk & spesifikasi
- `tentang.html` — Tentang kami & proyek
- `estimasi.html` — Kontak dan kalkulator estimasi

Buka `index.html` langsung atau jalankan server statis dari folder ini, misalnya `python -m http.server 8000`, lalu kunjungi `http://localhost:8000`.

Form estimasi menghitung kisaran awal Rp1,2–1,8 juta per opening dan menyusun detail permintaan untuk dikirim melalui WhatsApp. Harga ini indikatif dan perlu dikonfirmasi oleh estimator setelah dimensi serta spesifikasi proyek diketahui. Pengiriman formulir membuka WhatsApp di browser; tidak ada backend/CRM yang terhubung.

## Publikasi

Situs ini berupa file statis dan dapat dipublikasikan lewat GitHub Pages. Unggah file situs ke branch `main`, lalu aktifkan **Settings → Pages → Deploy from a branch → `main` / `/(root)`**. GitHub akan memberikan URL publik setelah proses publikasi selesai.
